# 赛博琥珀 0.2.0 · Windows x64

给DeepSeek Harness提供两个工具：下载单个视频，或从链接／本地视频制作GIF。
文件保存在本地，供用户或其他插件继续使用。

- `amber_download_video`：默认1080p以内最佳可用视频与音轨，保留原片。
- `amber_make_gif`：默认长边640、20fps、Q75/M75/L75，支持起止时间与体积上限。
- 体积受限时实测降低Q/L，保持尺寸、帧率、M和片段不变；不能达标时返回取舍建议。
- 内置固定版本yt-dlp、FFmpeg/ffprobe、Gifski及配套运行文件，无需另装Python或编码器，无安装期下载。

## 安装

需要Windows x64（最低Windows 10 22H2）与DSH；已验证DSH 0.2.1-rc.3。
在DSH可用的终端中执行：

```powershell
dsh plugin --profile desktop add 'https://github.com/MagneticLine/dsh-cyber-amber/releases/download/v0.2.0/dsh-cyber-amber-0.2.0.tgz'
```

四个程序路径配置留空即使用内置版本。安装后若工具未出现，重启DSH或新建会话。
请安装本页tgz；GitHub自动生成的Source code压缩包不含程序二进制。

## 验证与边界

32项自动测试通过，无失败或跳过；完成隔离宿主及真实desktop会话工具验收。
B站样例下载包含1080p视频与音轨；2–6秒GIF为640×400、20fps、80帧、4秒，
3MB上限下产物2,969,452字节。还验证了极小预算的needs_adjustment分支及取消、清理。
其他平台尚未实测；登录、访问验证及网络限制仍适用；本版不处理HDR色调映射。

不上传、不评论、不发布媒体，不包含ASR或视频内容分析。
