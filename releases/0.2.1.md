# 赛博琥珀 0.2.1

赛博琥珀为 DeepSeek Harness 提供视频下载和 GIF 制作工具。把视频链接、BV 号或本地文件交给 DSH，告诉它想保留的片段和效果，就能把喜欢的一段保存成 GIF。

默认使用 Gifski，长边 640、20fps、Q75／M75／L75、无限循环。

## 支持的功能

- **下载视频**：保留视频原片，默认选择 1080p 以内的视频与可用音轨。
- **截取并制作 GIF**：支持链接、BV 号和本地视频，可指定起止时间、尺寸、帧率与 Q/M/L 画质。
- **控制体积**：指定“不要超过 3MB”等目标后，自动尝试降低 Q/L，保留尺寸、帧率和片段；仍无法满足时给出取舍建议。
- **自定义默认参数**：在插件设置里调整画质、片段时长和保存目录，也可配置 Cookie 或下载代理。

## 安装

**Windows x64 · DSH 0.2.1-rc.3**

```powershell
dsh plugin --profile desktop add 'https://github.com/MagneticLine/dsh-cyber-amber/releases/download/v0.2.1/dsh-cyber-amber-0.2.1.tgz'
```
