# 赛博琥珀 0.2.1 · Windows x64

为 DeepSeek Harness 提供视频下载和 GIF 制作工具，文件保存在本地，可交给用户或其他插件继续处理。

- `amber_download_video`：下载单个视频，默认选择 1080p 以内最佳可用视频与音轨，返回文件路径、媒体信息、`has_audio` 和 `audio_codec`。
- `amber_make_gif`：从链接、BV 号或本地视频制作 GIF。默认长边 640、20fps、Q75／M75／L75、normal、无限循环，不放大小尺寸原片或补高帧率。
- 可指定起止时间、尺寸、帧率、Q/M/L 和体积上限。超限时实测降低 Q/L，保持尺寸、帧率、M 和片段不变；无法达标时返回 `needs_adjustment` 与取舍建议。
- 内置固定版本 yt-dlp、FFmpeg／ffprobe、Gifski 及支持文件，无安装期下载，不自动更新编码器。

## 本版改进

- 区分下载器、FFmpeg、Gifski 与文件错误；保留初始失败原因，清理异常作为补充。成品有效但清理失败时通过 `warnings` 报告。
- 统一配置页与运行时约束；补充中文说明、音轨信息和来源链接脱敏。
- 修正非方形像素与旋转视频的显示比例处理，补测可变帧率、低帧率和短片段。
- 补充依赖源码、构建记录、许可和署名资料，并校验实际安装包及隔离 DSH 安装后的内容。

0.2.1 与已验收的 0.2.1-rc.2 使用相同工具实现和固定依赖；正式版调整版本号与发行文档。

## 安装

仅支持 Windows x64，最低系统为 Windows 10 22H2；实际验证宿主为 **DSH 0.2.1-rc.3**。
其他宿主版本、macOS、Linux、Windows ARM64 或 32 位未验证／不支持本安装包。

```powershell
dsh plugin --profile desktop add 'https://github.com/MagneticLine/dsh-cyber-amber/releases/download/v0.2.1/dsh-cyber-amber-0.2.1.tgz'
```

已安装旧版时先记下配置，再通过宿主移除并添加新包。四个程序路径留空使用内置版；
仅显式填写路径时使用外部程序。工具未出现时刷新宿主或新建会话。

请安装本页 tgz，并核对 `SHA256SUMS-0.2.1.txt`。GitHub 自动生成的 Source code
压缩包不含固定程序二进制，不能代替安装包。无需另装 Python、下载器或编码器。

## 验证与边界

rc.2 在实际用户 DSH 会话中通过 B 站 `BV1RwnQ6sEd5` 下载及音轨验证；2–6 秒、
3MB 上限产物为 640×400、20fps、80 帧、4 秒、无限循环、2,969,452 字节，
最终 Q53／M75／L53。极小预算返回 `needs_adjustment`，未擅自改尺寸或帧率。
该结果是 rc.2 的用户验收，不冒充正式版的新平台下载实测。

正式包本地 Node 22／24 各 49 项测试、Python 10 项测试均通过，无跳过；
实际 tgz 在隔离 DSH 中完成 5 次工具调用及 GIF 全帧解码，临时目录已清理。
详情见 [发行校验报告](https://github.com/MagneticLine/dsh-cyber-amber/blob/v0.2.1/releases/0.2.1-win32-x64.json)。其他下载平台尚未实测；
登录、Cookie、访问验证、上游变化和网络限制仍然适用。拒绝 HDR 输入，不提供色调映射。
没有 ASR、视频内容理解、上传或评论功能。不设严格磁盘配额，不自动清扫崩溃残留。
