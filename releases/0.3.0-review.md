# 赛博琥珀 0.3.0 本地交付

TypeScript 迁移版。仅在本地制作和验证，尚未推送、发布 Release 或提交市场 PR。
原有 0.2.1 文档、发行记录和安装包保留；本版本新增的说明不替换它们。

## 本地安装

```powershell
dsh plugin add file:F:/Project/03-Tools-Automation/DSH-plugin/dsh-cyber-amber/dist/dsh-cyber-amber-0.3.0.tgz
```

安装包：`dist/dsh-cyber-amber-0.3.0.tgz`，93,693,057 字节。

SHA256：`37a5a36dbf90b82d54615b4c5690dd11af782d2f1f34c1ded4d1d77e4a5a0dad`。

可以对 DSH 说：

> 确认赛博琥珀版本是 0.3.0。下载 BV1RwnQ6sEd5，再用下载的本地文件制作 2–6 秒、最多 3MB 的 GIF，其余参数默认。检查成品存在、尺寸、帧数和体积，并说明是否有临时残留。

## 这次变更

- 核心源码迁移到 `src/*.ts`，开启严格类型检查；`lib/` 为编译生成的 JS、声明和 source map。
- 编译器、Node 类型和 DSH 开发依赖使用固定版本及 npm 锁文件。
- 工具输入、配置、制作结果和子进程接口补齐类型；JSON 元数据和依赖清单增加格式校验。
- Gifski 的未使用标准输出改用 SDK 支持的有界收集。
- 编译接入测试、打包和 Windows CI。安装包自带编译结果，不运行安装脚本。

默认仍为长边 640、20fps、Q75／M75／L75；体积搜索保持当前尺寸、帧率、M 和片段，只按既定规则降低 Q/L。

结果见 [验证记录](0.3.0-win32-x64.json)。运行日志在 `.validation/candidate-0.3.0/`。

- Node 22.20.0 与 24.21.0 各 52 项通过、无跳过；Python 发行检查 10 项通过。
- 编译产物重复构建一致，公开类型声明通过正反向编译检查。

- 固定二进制与许可资料沿用原有版本；检查安装包内 158 个依赖文件及 TS 源码对应关系。
