# 赛博琥珀 0.3.0

下载视频，或把视频链接、本地视频中的片段制作成高质量 GIF。默认长边 640、20fps、Q75／M75／L75；指定体积上限时自动实测并降低画质，也支持自定义参数。

这一版将插件迁移到 TypeScript，补齐工具参数、制作结果和宿主接口的类型检查，便于后续维护；同时改善异常媒体信息的错误处理。

支持 Windows x64，内置固定版本的下载器和编码器。

可以下载并保留原片，也可以直接从链接制作 GIF；支持秒数和时间码选取片段，成品保存在会话工作目录的 `cyber-amber` 文件夹，供保存或交给其他插件使用。

```powershell
dsh plugin --profile desktop add 'https://github.com/MagneticLine/dsh-cyber-amber/releases/download/v0.3.0/dsh-cyber-amber-0.3.0.tgz'
```

用法和参数见 [README](https://github.com/MagneticLine/dsh-cyber-amber#readme)。
