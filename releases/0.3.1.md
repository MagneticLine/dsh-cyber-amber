# 赛博琥珀 0.3.1

修复 DSH 更新到 0.2.1-rc.5 后，插件因版本限制无法加载的问题。兼容声明改为 DSH 0.2 系列（从 0.2.1-rc.3 起），后续兼容的客户端更新无需逐次更新插件。

视频下载、GIF 制作和体积控制保持原有行为，默认长边 640、20fps、Q75／M75／L75。

支持 Windows x64，内置固定版本的下载器和编码器。

```powershell
dsh plugin --profile desktop add 'https://github.com/MagneticLine/dsh-cyber-amber/releases/download/v0.3.1/dsh-cyber-amber-0.3.1.tgz'
```

用法和参数见 [README](https://github.com/MagneticLine/dsh-cyber-amber#readme)。
