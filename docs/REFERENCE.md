# 参数与配置

## 下载视频

工具 `amber_download_video` 接受以下参数：

| 参数 | 说明 |
|---|---|
| `url` | 必填：HTTP(S) 视频链接、BV 号或 av 号 |
| `output_dir` | 可选：保存目录 |

默认选择 1080p 以内最佳可用视频与音轨，下载单个视频，成品保留。
返回路径、分辨率、时长、帧率、大小、`has_audio`，以及有音轨时的 `audio_codec`。
无音轨的原片也可下载。来源地址会移除鉴权查询参数，仅保留已知视频定位参数。

## 制作 GIF

工具 `amber_make_gif` 接受以下参数：

| 参数 | 默认与说明 |
|---|---|
| `source` | 必填：视频链接、BV 号或本地视频绝对路径 |
| `start` / `end` | 默认从 0 到片尾；支持秒、小数秒、中英文冒号时间码 |
| `long_edge` | 640；范围 128–1920，保持显示比例，不放大原片 |
| `fps` | 20；范围 1–30，不超过原片平均帧率 |
| `quality` | Q75；范围 1–100，默认 L 随 Q 调整 |
| `motion_quality` | M75；范围 1–100，独立于 Q/L，不代表帧率百分比 |
| `lossy_quality` | 默认等于 Q；可以独立指定 |
| `max_size_mb` | 可选，正数；1MB＝1,000,000 字节 |
| `min_quality` | 体积搜索最低 Q/L，默认 50 |
| `output_dir` | 默认会话工作目录下的 `cyber-amber` 文件夹 |

起止时间越界时自动贴合片头、片尾；没有有效画面则报错。
默认片段上限为 30 秒，超长时需要指定片段或调整 `maxClipSeconds`。
GIF 时长按百分之一秒量化，相同画面可能合并为更少的编码帧。
VFR 原片按平均帧率限制采样；HDR、未知像素比例或非直角旋转目前会报错。

## 体积上限

指定 `max_size_mb` 后，复用同一原片实测编码，保持尺寸、帧率、M 和时间范围不变。
如果 Q=L 且超限，从所选画质向下搜索至 `min_quality`，检查相邻整数，最多编码十次。
不为了填满预算提高画质；独立指定不同 Q/L 时不自动修改这组参数。

未找到合格结果时返回 `needs_adjustment`，包含目标体积、最小实测体积、实际尝试和取舍建议。
尺寸和帧率建议是估算，质量建议也需实际重试验证；由用户选择后再调用。
缩尺寸会影响文字和细节，降帧率会影响动作连续性，降 Q/L 可能增加噪点、色块。
实验依据见 [QUALITY.md](QUALITY.md)。

## 插件设置

| 配置项 | 默认与说明 |
|---|---|
| `outputDir` | 空：会话工作目录下的 `cyber-amber` |
| `ffmpegPath` / `ffprobePath` / `gifskiPath` / `ytdlpPath` | 空：使用内置程序；填写后使用指定路径 |
| `cookiesFile` | 空：不带 Cookie；需要登录时填写 Netscape Cookie 文件绝对路径 |
| `proxy` | 空：不额外指定代理；系统路由和环境代理仍可能生效 |
| `sourceHeight` | 1080：下载格式高度上限 |
| `longEdge` / `fps` / `quality` / `motionQuality` | 640／20／75／75 |
| `maxClipSeconds` | 30：单个 GIF 片段时长上限 |
| `timeoutMs` | 300000：排队、下载、探测及所有编码尝试的总时限 |
| `maxPending` | 3：包含一个执行中的任务，最多再排队两个 |
| `maxSourceMB` | 512：原片大小上限 |
| `maxOutputMB` | 0：不额外限制成品；非 0 时超限报错，不自动降质 |

通过 profile patch 覆盖 `config` 时，DSH 使用整对象替换，需要保留其他已修改字段。
无会话的程序调用需提供绝对 `output_dir` 或绝对配置 `outputDir`。
Cookie 文件只交给 yt-dlp，不读取浏览器或其他插件的登录态。

## 文件保存

下载工具的成品保留；从链接制作 GIF 的临时原片、试编码和失败产物在任务结束后清理。
本地原片不修改。成品使用唯一文件名，保存在输出目录，由用户管理。

成品有效但清理失败时仍保留成品，并返回 `warnings`；无法确认进程退出时保留任务目录。
原片／成品大小上限不是峰值磁盘配额。强制结束宿主或断电可能留下 `.amber-*` 目录，
确认对应任务已经停止后，可以按错误提示的具体目录清理。

内置版本与第三方程序来源见 [NOTICE.md](../NOTICE.md)。
